# Saigon Protocol

See `SEA_CYBERPUNK_GDD.md` for design and `SAIGON_PROTOCOL_ARCHITECTURE.md` for technical architecture.

## Stack

React 19 + TypeScript + Vite, Zustand for state, Tailwind CSS v4, inkjs for narrative.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run lint` — run oxlint
- `npm run preview` — preview a production build locally
